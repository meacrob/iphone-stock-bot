iPhone Duo 256GB auto-checkout bot (Windows)
=============================================
It watches Apple TRX every ~15s. When a Duo 256GB (any colour) can be picked up,
it opens your bag, checks out, picks TRX pickup, fills your details and STOPS at
payment. Then it beeps and pings Telegram. You pick the card, enter OTP, place order.
It never pays by itself.

Run order: 1-setup.bat -> edit config.ini -> 2-login.bat -> 3-practice.bat -> 4-start.bat
Keep the PC plugged in. Don't close the black window or the browser it opens.
Screenshots of each step go to the "screenshots" folder (send them to Claude if it gets stuck).
